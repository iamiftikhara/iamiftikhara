## Selected Work

### 🏛️ PMTS: Project Monitoring & Tracking System for BSDI
Government platform that moved development-project tracking off files and spreadsheets into one auditable system.
- Built end to end with Python, Django, DRF and PostgreSQL: approval workflows (approve, reject, return, remarks) with a full audit trail
- Role-based plus district- and region-level access control, so each official sees only their area
- Docker, Gunicorn and Nginx with separate dev and production; nightly `pg_dump` backups with failure alerts

### 🛒 Rutland London: luxury bathroom brand on Shopify
- Run three international stores (UK, US, UAE) with **1,300+ products** and **22,000+ variants**
- Custom theme, quote-request flow for bespoke orders, hreflang international SEO and tracking stack

### 🛡️ Cytex: cybersecurity & compliance CRM for SMBs
- Lead the front-end architecture and UI style guide; built AI-powered chat and risk-analysis features in React and Next.js
